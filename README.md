# 3xui_install

Установка VPN-сервера (3x-ui + Xray) на чистой Ubuntu 22/24.

## Актуальный скрипт — `3xui_install3.sh`

Схема без обратного прокси: панель сама держит защищённое соединение,
сертификат Let's Encrypt на голый IP и его продление делают штатные средства 3x-ui.

```bash
systemctl stop unattended-upgrades
bash <(curl -Ls https://raw.githubusercontent.com/zhiharevds/3xui_install2/main/3xui_install3.sh)
```

Скрипт отказывается работать, если на сервере уже установлен x-ui: он сбрасывает
файрвол и пароль панели, поэтому запускать его можно только на чистой системе.

Настройки — переменными окружения перед запуском:

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `DEFAULT_EXIT` | `direct` | выход по умолчанию: `direct` или `warp` |
| `DO_WARP` | `1` | ставить ли Cloudflare WARP |
| `DO_UPGRADE` | `1` | обновлять ли систему перед установкой |
| `CREATE_INBOUNDS` | `1` | создавать ли подключения автоматически |
| `CLIENTS` | `Keenetic belka mama dzh` | список клиентов |
| `SUB_PORT` | `2096` | порт подписок |
| `PORT_REALITY` / `PORT_XHTTP` | `443` / `8080` | порты подключений |
| `FORCE` | `0` | `1` — работать даже на непустом сервере |

## Старый скрипт — `3xui_install2.sh`

Оставлен для истории. Ставил дополнительно Caddy как обратный прокси и требовал
ручных доделок: прописать сертификат панели, добавить перезапуск панели в хук
продления, задать «мин. версию клиента» для mihomo. В третьей версии всё это
делается само.
